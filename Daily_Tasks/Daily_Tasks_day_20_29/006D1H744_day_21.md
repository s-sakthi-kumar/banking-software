1. Node.js vs Apache/Nginx

Node.js is a JavaScript runtime used to build server-side applications and APIs.
Apache/Nginx are traditional web servers mainly used to serve HTTP requests, static files, and act as reverse proxies.

2. Event-driven architecture

Node.js works based on events and callbacks rather than waiting for each operation to finish.
When an operation completes, its callback is handled by the event loop.

3. Single-threaded model and concurrency

Node.js uses a single main thread for executing JavaScript but handles I/O operations asynchronously.
The event loop allows it to handle many requests without creating a separate thread for each one.

4. Role of V8 engine

V8 is Google's JavaScript engine used by Node.js to execute JavaScript code.
It also uses JIT compilation to convert JavaScript into efficient machine code.

5. Why Node.js is non-blocking

Node.js doesn't wait for I/O operations like file or database operations to finish before continuing.
Instead, it starts the operation and uses callbacks/events to handle the result when it is ready.

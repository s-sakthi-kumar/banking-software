### Task 1: What is data binding?

**Data binding** is the process of connecting the user interface (UI) with data so that changes in data are automatically reflected in the UI and vice versa.

---

### Task 2: One-way data binding and two-way data binding

**One-way data binding:**
Data flows only in one direction, usually from the component/data source to the UI. Changes in the UI do not update the data automatically.

**Two-way data binding:**
Data flows in both directions. Any change in the UI updates the data, and any change in data updates the UI automatically.

---

### Task 3: When do you use one-way and two-way data binding? Give examples.

**One-way data binding is used** when data only needs to be displayed and does not require user modification.
**Example:** Displaying a username or product list in a React application.

**Two-way data binding is used** when user input needs to update the application data immediately.
**Example:** Forms, search boxes, and login fields where user input updates the state.

---

### Task 4: What is state in React?

**State** is a built-in object in React that stores data or information about a component. It allows components to create dynamic and interactive behavior by updating the UI when the state changes.

---

### Task 5: Explain SPA.

**SPA (Single Page Application)** is a web application that loads a single HTML page and dynamically updates content without refreshing the entire page.
**Example:** React applications use SPA architecture to provide faster navigation and a better user experience.

---

### Task 6: What is DOM?

**DOM (Document Object Model)** is a programming interface that represents an HTML document as a tree structure of objects. It allows JavaScript to access and modify webpage content, structure, and styles dynamically.

---

### Task 7: What is Virtual DOM?

**Virtual DOM** is a lightweight copy of the actual DOM used by React. When changes occur, React updates the Virtual DOM first, compares it with the previous version, and updates only the necessary parts of the real DOM, improving performance.

---

### Task 8: What are props in React? Explain prop drilling.

**Props** are read-only data passed from a parent component to a child component in React. They help components share information.

**Prop drilling** is the process of passing props through multiple components just to reach a deeply nested component, even when intermediate components do not need the data.

---

### Task 9: Why do we use React? Give importance.

React is a JavaScript library used for building fast and interactive user interfaces.

**Importance of React:**

* Uses reusable components, making development easier.
* Provides Virtual DOM for better performance.
* Supports component-based architecture.
* Enables creation of single-page applications.
* Has strong community support and many useful libraries.

---

### Task 10: What is component-based architecture?

**Component-based architecture** is a design approach where an application is divided into small, reusable, independent components. Each component manages its own logic and UI, making applications easier to develop, test, and maintain.


### Task 11: Lifecycle of a react compnent

![](../../assets/react-lifecycle%20.png)

**React component lifecycle** describes the different stages a component goes through from creation to removal.

**1. Mounting:**
The phase when a component is created and added to the DOM.

* `constructor()` → Initializes state and methods.
* `render()` → Displays the UI.
* `componentDidMount()` → Runs after the component is added to the DOM (API calls are usually done here).

**2. Updating:**
Occurs when state or props change.

* Component re-renders with new data.
* `componentDidUpdate()` runs after updates are completed.

**3. Unmounting:**
The phase when a component is removed from the DOM.

* `componentWillUnmount()` is used for cleanup tasks like removing timers or event listeners.

### Task 12: What are Hooks in React? Why use Hooks? Types of Hooks.

**Hooks** are special functions introduced in React that allow functional components to use state and other React features without writing class components.

**Importance of Hooks:**

* Allow state management in functional components.
* Reduce complex class-based code.
* Help reuse logic between components.
* Improve code readability and maintainability.

**Different types of React Hooks:**

1. **useState()**

   * Used to create and manage component state.
   * Example: Managing form input values.

2. **useEffect()**

   * Used for side effects like API calls, timers, and updating the DOM.

3. **useContext()**

   * Used to access data from React Context without passing props.

4. **useReducer()**

   * Used for managing complex state logic.

5. **useRef()**

   * Used to store mutable values and access DOM elements directly.

6. **useMemo()**

   * Optimizes performance by storing calculated values.

7. **useCallback()**

   * Prevents unnecessary function recreation during re-renders.

---

### Task 13: What is React Redux architecture? Explain in detail.

**React Redux** is a state management library used with React applications to manage global application data in a predictable way.

1. **Store:**
   * A central place where the entire application state is stored.
   * Only one store is maintained in a Redux application.

2. **Action:**
   * An object that describes what change needs to happen.
   * It sends information to the reducer.

3. **Reducer:**
   * A pure function that receives the current state and action.
   * It creates a new updated state.

4. **Dispatch:**
   * A method used to send actions from components to the Redux store.

5. **Selectors:**
   * Used to read required data from the Redux store.

**Advantages of Redux:**
* Provides centralized state management.
* Makes data flow predictable.
* Easier debugging and testing.
* Useful for large applications with complex data sharing needs.

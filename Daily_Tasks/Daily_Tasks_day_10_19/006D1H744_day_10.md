## Day 10

### Task 1

What is spring data JPA?

Spring Data JPA is a framework that simplifies database access in Spring Boot applications by providing an abstraction layer over the Java Persistence API (JPA). It enables seamless integration with relational databases using Object-Relational Mapping (ORM), eliminating the need for boilerplate SQL queries.

With Spring Data JPA, developers no longer need to:
1. Manually write DAO implementations.
2. Manage EntityManager directly.
3. Write repetitive CRUD queries

### Task 2

What are the key features of Spring data JPA?

1. **Repository Abstraction:** Spring Data JPA provides interfaces like JpaRepository to perform CRUD operations without writing SQL queries.
2. **Query Methods:** We can define methods like findByName() or findByAgeGreaterThan() and Spring automatically generates the query.
3. **Pagination and Sorting:** Supports pagination and sorting using built-in methods like findAll(Pageable pageable).
4. **Custom Queries:** Allows writing custom queries using @Query annotation (JPQL or native SQL).
5. **Integration with JPA:** Works with JPA providers like Hibernate to map Java objects to database tables.

### Task 3 

What are core components of Spring data JPA?

* Entity -> Represents a table in the database
* Repository -> Interface for database operations
* Service Layer -> Contains business logic
* JPA Provider -> Implementation (e.g., Hibernate)

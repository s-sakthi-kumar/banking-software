### Task 1

What is spring data JPA?

Spring Data JPA is a framework that simplifies database access in Spring Boot applications by providing an abstraction layer over the Java Persistence API (JPA). It enables seamless integration with relational databases using Object-Relational Mapping (ORM), eliminating the need for boilerplate SQL queries.

With Spring Data JPA, developers no longer need to:
1. Manually write DAO implementations.
2. Manage EntityManager directly.
3. Write repetitive CRUD queries

### Task 2

What are the key features of Spring data JPA?

1. **Repository Abstraction:** Spring Data JPA provides interfaces like JpaRepository to perform CRUD operations without writing SQL queries.
2. **Query Methods:** We can define methods like findByName() or findByAgeGreaterThan() and Spring automatically generates the query.
3. **Pagination and Sorting:** Supports pagination and sorting using built-in methods like findAll(Pageable pageable).
4. **Custom Queries:** Allows writing custom queries using @Query annotation (JPQL or native SQL).
5. **Integration with JPA:** Works with JPA providers like Hibernate to map Java objects to database tables.

### Task 3 

What are core components of Spring data JPA?

* Entity -> Represents a table in the database
* Repository -> Interface for database operations
* Service Layer -> Contains business logic
* JPA Provider -> Implementation (e.g., Hibernate)

### Task 6: What is `application.properties` file is about?

The `application.properties` file is the default configuration file in Spring Boot used to store application settings such as server port, database connection, and logging configurations.
It allows developers to manage application configuration externally without changing the source code.

### Task 7: Why use `application.properties`?

`application.properties` centralizes application configuration, making it easier to manage and modify settings for different environments.
It improves maintainability by separating configuration from the application code.

### Task 8: What is `application.yml`?

`application.yml` is an alternative Spring Boot configuration file that uses YAML (YAML Ain't Markup Language) syntax instead of key-value pairs.
It provides a cleaner and more readable way to organize complex and hierarchical configurations.

### Task 9: Why use/prefer `application.yml` instead of `application.properties`?

`application.yml` is preferred because it is more readable and supports nested configurations without repeating property names.
It simplifies the management of complex configurations, especially in large Spring Boot applications.

### Task 10: What is Eureka Server?

Eureka Server is a service registry provided by Spring Cloud Netflix that helps microservices register and discover each other automatically.
It enables dynamic service discovery, eliminating the need to hardcode service addresses.

### Task 11: Purpose of Eureka Server

The main purpose of Eureka Server is to maintain a registry of all available microservices in a distributed system.
It helps clients locate services dynamically, improving scalability, load balancing, and fault tolerance.

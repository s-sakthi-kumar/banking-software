>What do you understand by Spring frame work?

Spring framework is used to create large enterprice application with a lot of features;
1. Dependency Injection
2. Configuration
3. Dependency Management: like package manager(downloads and manages all the required package)
4. Provides a lot of features for accelerated developement.
    1. Lifecycle management
    2. Modules
    3. Beans
### Task 2

>What is Sprint Boot? 

Spring Boot is a framework built on top of spring and provides a lot of features on top of Spring
1. Provides Auto Configuration, needs minimal manual Configuration
2. Simplified Dependency management.
3. Easier and faster developement when compared to spring as it reduces a lot of manual work
and automatically does a lot of work.
4. uses a lot of Defaults.


### Task 3

>What is the diff b/w Spring framework and Spring Boot

1. Both are used to create large applications(mostly web apps)
2. Boot is built on top of spring and provides a lot of features and defaults on top of spring.
3. In spring we have to do a lot of manual configuration, Boot provides a lot of auto configuration and managed dependency.
4. Spring does not have a external server, Boot has inbuilt or it comes with with embedded servers.
5. Boot provides a lot of abstraction for manual config and setup in Spring, so developement speed is higher.
